# everyday and epic

李之延冰 · MA Fashion Photography · LCF / UAL

A personal photography website. The same set of photos can be read from the innermost to the outermost, or from the outermost to the innermost — same images, different directions, same arrival.

殊途同归.

---

## Local preview

Open `index.html` in any browser. All assets are local.

## Deployment

This is a static site. Deploys directly to Vercel or Netlify:
- Connect this repo
- No build command needed
- Output directory: root (`.`)

## Structure

```
index.html       — single-file HTML / CSS / JS
photos/          — all source photographs (53 files, ~16 MB)
```

## Notes

- Font: Cormorant Garamond (loaded from Google Fonts)
- All photos are pre-processed (EXIF rotation applied, max long edge 1800px, JPEG q85)
- The site has two reading directions, chosen by clicking one of the two opening faces
